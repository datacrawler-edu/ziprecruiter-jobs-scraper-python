# Run from Apify

Open [ZipRecruiter Jobs Scraper](https://apify.com/datascraperes/ziprecruiter-jobs-scraper?fpr=edudata). In Input, add job keywords, select usa or canada, and optionally enter a city such as New York, NY. Start with maxItemsPerQuery=3 and maxTotalItems=3. Keep optional filters broad initially. Click Start, inspect the run and Dataset, then export JSON, CSV or Excel. Review the completion summary when fewer jobs arrive; a requested limit is not a guaranteed count.
